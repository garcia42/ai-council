## Safe invalid-row projection

An identifiable invalid V2 row remains one denominator record, but downstream analyzers never
consume its untrusted nested values as if they were schema-valid. Report projection replaces or
guards malformed enum, identity, timestamp, outcome, seat, and finding values with explicit invalid
sentinels before membership, hashing, sorting, grouping, or arithmetic. Objects and arrays cannot
raise raw `TypeError` in data health.

## Policy bound to pinned snapshot destination

Snapshot policy approval is evaluated against the retained destination-parent dirfd and captured
repository/source directory identities, not against a pathname before pinning. The mutation-bound
check rejects a parent whose actual inode is the repository, a source, or nested within either,
even if namespace substitution occurred between lexical inspection and pinning. A verified snapshot
cannot be created in a forbidden inode.

## Bounded generic JSON parsing

Excessively nested valid JSON is an invalid input, not a process traceback. `RecursionError` and
equivalent decoder depth failures are normalized to the same fixed generic parse categories as
syntax, duplicate-key, non-finite, and encoding failures across JSONL ledgers, retained artifacts,
snapshot metadata, specs, and CLI boundaries. Caller or decoder text is never echoed.

## Typed resolution enums

Resolution `method`, `voidReason`, `status`, and every other closed V1/V2 resolution field are
text-validated before membership. Wrong-type valid JSON produces a typed domain error through both
the base resolution API and V2 wrapper, appends zero sidecar bytes, and never emits a traceback.
